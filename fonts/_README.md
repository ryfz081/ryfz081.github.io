# Fonts

`adventor-*.woff2` are **TeX Gyre Adventor**, a free revival of ITC Avant Garde Gothic
(GUST Font License, which allows redistribution). They're subset to Latin to stay small.

The site's font stack asks for ITC Avant Garde Gothic first, so it's used on any machine
that has it installed. ITC Avant Garde is a commercial Monotype font: to serve the real
thing to every visitor you need a web licence. If you get one, drop the .woff2 files in
this folder and point the `@font-face` rules at the top of `style.css` to them.
